# Security Policy - CyberCode Studio

## Reporting Vulnerabilities
CyberCode Studio takes security issues very seriously. If you discover a security vulnerability within this repository or associated API endpoints, please report it responsibly.

### Responsible Disclosure
- **Email**: Direct security disclosure to `security@cybercode.studio`
- **PGP Key**: Available upon request for encrypted communications.
- Please do **not** open public GitHub issues for undisclosed security vulnerabilities.

## Scope & Security Features
- **Authentication**: Bearer API Key authentication enforced on all API endpoints.
- **TLS**: Transmit encryption via TLS 1.3.
- **Vault Integration**: Support for HashiCorp Vault key management.
- **Anonymization**: PII and sensitive secret masking prior to processing datasets or prompt completions.
- **Bug Bounty**: CyberCode Studio operates an informal bug bounty program rewarding responsible disclosures.
