# Privacy Policy - CyberCode Studio

## Data Anonymization & Protection
CyberCode Studio is committed to ensuring total confidentiality for all code snippets, prompts, and analytical data processed through our AI services.

### Core Privacy Commitments
1. **Zero Data Retention for Inferences**: Code submitted to `/v1/chat/completions`, `/v1/completions`, or `/v1/security/audit` is processed in-memory and never stored on disk or used to retrain base models without explicit consent.
2. **PII & Secret Scrubbing**: Automated regex pattern matching removes personally identifiable information (PII), email addresses, credentials, and API tokens before fine-tuning datasets are saved.
3. **GDPR Rights**: Users retain full control over their data, including rights to data access and erasure.
